# 极简英文 · 听与练 (Minimal English Listener)

> 🎧 专为追求纯粹、沉浸式英语听力训练打造的极简精听对照与磨耳朵工具。

配合《极简英文·读与记》使用，助你实现**「听·读·记」**闭环。

---

## ✨ 核心特色功能

### 1. 听力原文存储与智能解析（可以存原文）
- **随时存储与编辑原文**：支持自定义添加听力文章，随意修改原文、补全译文或调整笔记。
- **智能断句**：自动根据标点符号规范切分成单句，支持纯英文、中英双语对照、以及带时间戳的 LRC / SRT 歌词字幕格式。
- **本地持久化安全存储**：
  - 音频文件存储于浏览器底层的 **IndexedDB** 数据库，几十兆的大音频文件也能持久保存在手机与电脑本地，无需重复上传，不消耗额外流量。
  - 原文、笔记与生词完全离线保存在本地，100% 隐私安全。

### 2. 三大专属精听对照模式（对照着看）
- **📖 精听对照模式 (Read-Along)**：
  - 播放时随音频进度自动高亮当前句子，并平滑滚动跟随。
  - 点击任意句子的时间戳标签即可瞬间跳播；点击单句循环按钮即可针对难句反复打磨。
  - **点词即查**：在原文中轻点任意单词，即刻弹出音标、中英释义、真人发音，并可一键加入生词本。
- **🙈 磨耳朵盲听模式 (Blind Mask)**：
  - 全篇原文采用毛玻璃模糊遮蔽，逼迫大脑依靠纯声音理解。
  - 遇到听不懂的盲点，**轻触句子即可瞬间刮开揭晓对照**，既练真听力，又能即时查缺补漏。
- **✍️ 听写核对模式 (Dictation & Diff)**：
  - 边听边键入你听到的英文句子。
  - 点击「核对对照」，内置算法会自动进行**词级差异对比（Diff）**：绿色标出听对词汇，红色删除线标出漏听词汇，橙色标出拼写误差，并实时给出听写准确率得分！

### 3. 为听力练习量身定制的播放控制
- **A-B 片段循环复读**：轻点设置 A 点，再次点击设置 B 点，即可针对任意 5 秒或 10 秒片段无缝循环，直到彻底听清每一个连读与弱读。
- **单句循环**：一键循环当前单句。
- **句末智能自动停顿**：播放完一句话后自动暂停 2 秒（可调节），专为**影子跟读（Shadowing）**与听写设计。
- **8 档精细变速**：支持 0.5x、0.75x、0.85x、1.0x、1.15x、1.25x、1.5x、2.0x 无级语速调节，声调自然不变调。
- **极速跳跃与快捷键**：支持 ±5 秒快进快退，电脑端支持「空格」播放/暂停、「左右方向键」快退快进、「R」复读单句、「L」循环。

### 4. 极致美学与护眼排版
- **三套优雅配色**：经典的「暖阳纸」、清爽的「极简白」与专注夜读的「深邃夜」。
- **字体与字号随心调**：支持经典优雅衬线体与现代清晰无衬线体切换，字号滑块无级调节。
- **PWA 原生体验**：支持添加到 iOS Safari 主屏幕或 Android Chrome，无地址栏全屏运行，离线可用。

### 手机添加到主屏幕（原生 App 般体验）

### 本地运行（可选）
在本地文件夹中双击 `start.bat`（或在终端运行 `python serve.py`），即可在本地浏览器体验。
